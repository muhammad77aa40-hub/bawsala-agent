# نادي الصحافة العراقية · الهوية البصرية

- `brand-guidelines.html` — دليل الهوية البصرية الكامل (افتحه بالمتصفح)
- `Iraqi-Press-Club-Brand-Guidelines.pdf` — نفس الدليل كملف PDF للطباعة والإرسال
- `logo/svg/` — ملفات الشعار الأصلية (النصوص محوّلة لأشكال، تكبر بلا حدود)
- `logo/png/` — نفس الملفات PNG بخلفية شفافة (حتى 2048px)
- `Iraqi-Press-Club-Logo-Files.zip` — كل ملفات الشعار بملف مضغوط واحد
