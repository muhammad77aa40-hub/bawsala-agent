# متجر معصرة الرافدين

متجر أونلاين لمعصرة الرافدين (زيوت، أعشاب، عناية بالشعر والبشرة) فيه مساعد ذكي يعتمد على Claude.

## شنو موجود
- واجهة عربية (RTL) نظيفة على ستايل أبل، وتشتغل بالوضع الفاتح والداكن وعلى الموبايل.
- ٨ أقسام، والباكجات، والبحث، وصفحة لكل منتج، والسلة، والطلب بالدفع عند الاستلام لكل المحافظات.
- مساعد ذكي يسأل عن المشكلة، ويقترح منتجات كبطاقات، ويضيفها للسلة، ويفتح صفحة الطلب، ويتابع حالة الطلب.
  إذا ماكو مفتاح API، يشتغل المساعد بقواعد جاهزة (وضع تجريبي).
- الطلبات تنحفظ بـ `data/orders.json`، والأسعار تنحسب بالسيرفر من الكتالوج. واختيارياً توصل رسالة واتساب لصاحب المحل بكل طلب.
- `GET /api/admin/orders` و `PATCH /api/admin/orders/:id` (مع الهيدر `x-admin-key`) لإدارة الطلبات.

## التشغيل
```
cp .env.example .env   # حط ANTHROPIC_API_KEY و ADMIN_KEY
npm install
npm start              # http://localhost:3000
```

## الألوان
كل ألوان الموقع بأول ملف `public/styles.css` (بلوك BRAND). لتطبيق ألوان شعار المعصرة بدّل `--brand` (الأخضر) و `--oil` (الكهرماني) بالوضعين الفاتح والداكن.

## تعديل المنتجات والأسعار
كل المنتجات بملف `public/catalog.js`. **الأسعار الحالية تجريبية**، لازم تتبدل بالأسعار الحقيقية.

`preview.html` نسخة بملف واحد للعرض فقط، تنفتح بالمتصفح مباشرة بدون سيرفر.
